# build your own.

A website you own: every page, every component and every line. It runs with no accounts or keys, and you add more one step at a time.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Funparty-app%2Funparty.app)

The button makes a private copy on your own GitHub account and puts it online on your own Vercel account. Both accounts are free to create. Your copy starts fresh, so later releases here don't reach it on their own.

## Then what

Open your site and follow the steps from `/article/setup-start-here`. If you get stuck, an LLM can help: tell it the step, what you expected and what you see, and never paste a key.

## On your computer

```bash
nvm install
npm ci
npm run dev
```

No `.env` needed to start. `.env.example` lists everything you can add.
